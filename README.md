# skills

Agent skills repo. You'll find skills here that I've created from copies of
official docs, or skills I've created based on my own tastes and habits.

You can find all skills here on skills.sh.

## Formatting

Install Oxfmt globally with `npm install --global oxfmt@0.79.0`.
Run `oxfmt .` to format the repository or `oxfmt --check .` to check formatting.
Settings live in `.oxfmtrc.json`.
